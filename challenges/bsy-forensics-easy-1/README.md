# Neon Runner: Quiet Shift

A backdoored CI runner is still humming in a neon corporate datacenter. Its build queue looks quiet, but someone has already been inside. Reconstruct the host's recent activity and recover the evidence the intruder left behind.

The runner is reachable from inside the lab network. Scan `172.20.0.0/24`; challenge hosts are assigned addresses in `172.20.0.141-199`. Use the supplied login to inspect the host's accounts, records, scheduled work, timestamps, privilege activity, and shell history.
