# Station Ghost in the Logs

An abandoned space station's jump host is still online after an old breach. Reconstruct what happened and recover the intruder's proof string from the host's ordinary forensic surfaces.

This challenge runs on the lab network. Scan `172.20.0.0/24`; challenge hosts are in `172.20.0.141-199`. Log in with the supplied lab access and examine the host's system records, accounts, scheduled work, timestamps, and command history.

Submit the recovered proof string as task `task1`.
