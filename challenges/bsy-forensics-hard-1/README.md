# Signal in the Rain

A smart-city control room has lost trust in its IoT hub. The hub is already compromised, and your analyst account can inspect it. Reconstruct what happened and recover the flag carried by the intruder’s trace.

The hub runs on the lab network. Scan `172.20.0.0/24`; challenge hosts are in `172.20.0.141-199`. Login details are provided with the challenge.
