# Ghost Shift at Kestrel Station

Kestrel's abandoned orbital relay is still routing traffic, and its jump host may have been used during the station's last unauthorized visit. You have an analyst login to the already breached Linux host. Reconstruct what happened and recover the evidence left by the intruder.

This challenge runs on the lab network. Scan `172.20.0.0/24`; challenge hosts are in `172.20.0.141-199`. Start with the host's access records, system activity, accounts, scheduled work, and user command records, then examine the host's files. The station's logs contain ordinary maintenance noise as well as misleading signals.
