# Night Shift at the Neon Foundry

Neon Foundry's build server kept the megacorp's retrocomputing line alive. After a suspicious overnight shift, the operations crew needs a clear account of what happened and the evidence the intruder left behind.

Log in to the host and reconstruct the timeline from its users, logs, scheduled work, shell records, and file metadata. Recover the evidence from the compromised server.

The host runs on the lab network. Scan `172.20.0.0/24`; challenge hosts are in `172.20.0.141-199`.
