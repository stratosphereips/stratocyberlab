# Ghost in the Build Server

The night shift at a cyberpunk megacorp's build server left a messy audit trail. Somewhere among routine operations, an intruder's work has been mixed in.

Investigate the compromised host, reconstruct what happened, and recover the concealed flag. The host runs on the lab network. Scan `172.20.0.0/24`; challenge hosts are in `172.20.0.141-199`. Use the challenge's provided SSH credentials.
