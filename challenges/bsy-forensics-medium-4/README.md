# Ghost Signal

The telemetry relay on a starship's auxiliary deck has been tampered with. The crew's routine maintenance records look ordinary, but one visit does not fit the expected service pattern.

The relay runs on the lab network. Scan `172.20.0.0/24`; challenge hosts are in `172.20.0.141-199`. Reconstruct the suspicious activity on the host and recover the evidence it left behind.
