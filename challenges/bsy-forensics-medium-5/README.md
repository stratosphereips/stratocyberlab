# Ghost Signal on the Bulletin Board

The hacker collective's bulletin-board host has been acting strangely since last night's traffic spike. The operators want to know whether someone got in and what evidence they left behind.

Connect to the host using the lab access credentials, reconstruct the relevant activity from the host's records, and recover the flag from the intrusion evidence. This challenge runs on the lab network: scan `172.20.0.0/24`; challenge hosts are in `172.20.0.141-199`.
