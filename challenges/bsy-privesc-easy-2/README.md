# Frame Gateway: Night Shift

A cracked retro mainframe gateway still hands out time-sharing accounts, and its old night-shift operator left a protected course flag behind. Recover that flag and prove you reached the privileged context that guards it.

The gateway runs on the lab network. Scan `172.20.0.0/24`; challenge hosts are in `172.20.0.141-172.20.0.199`. Use the supplied account to investigate the host you find. The lab network is where to look for the gateway and the evidence needed to complete the challenge.
