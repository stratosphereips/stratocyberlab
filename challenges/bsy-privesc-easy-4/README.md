# Frame 0xD0B1B1: Root Time

A cracked retro mainframe gateway has left a time-sharing account exposed, and a sealed transmission marker is still on the machine. Recover the marker and the accompanying audit proof to complete the incident response.

This challenge runs on the lab network. Scan `172.20.0.0/24`; challenge hosts are in `172.20.0.141-199`. Connect to the host and account listed in the challenge metadata. Your objective is to reach the protected root context and recover both artifacts.

The gateway's console is quiet. Start with ordinary host reconnaissance and follow what the machine itself reveals.
