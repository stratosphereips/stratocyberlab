# Lunar Relay

A research cluster login node on a lunar base has gone quiet, and the night shift needs its challenge signal recovered. Connect to the host, investigate its local state, and recover the flag while verifying elevated access.

The box is on the lab network. Scan `172.20.0.0/24`; challenge hosts are in `172.20.0.141-199`. Use the SSH credentials listed in the challenge access details.
