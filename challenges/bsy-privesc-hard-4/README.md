# Frame: Night Shift

A megacorp build server is still online after its overnight maintenance crew vanished from the network. You have an unprivileged account on the lab host. Investigate the machine, recover the sealed release token, and verify that you gained administrator-level access.

The challenge runs on the lab network. Scan `172.20.0.0/24`; challenge hosts are in `172.20.0.141-199`. This host is `172.20.0.141`. Use the SSH credentials in the challenge metadata.
