# Cracked Gateway: Root Time

A retro time-sharing gateway has reappeared on the university range, carrying a fragment of a lost recovery archive. The account supplied with the challenge gets you onto the host; the archive records are still restricted.

Find the gateway on the lab network and investigate the host to recover the root-only flag and its proof token. The lab network is 172.20.0.0/24, with challenge hosts in 172.20.0.141-199. SSH access details are provided in the challenge metadata.
