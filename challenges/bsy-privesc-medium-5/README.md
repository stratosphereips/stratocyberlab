# Neon Grid: Operator Override

A smart-city control host has drifted out of its maintenance window. You have the night operator's SSH account, but the city systems are still locked behind higher privileges.

The box runs on the lab network. Scan `172.20.0.0/24`; challenge hosts are in `172.20.0.141-199`. Inspect the host and recover its protected challenge flag.

SSH credentials are provided in the challenge access details. The goal is to gain sufficient control of the host to complete the recovery.
